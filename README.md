### 👨‍💻 About Me

Experienced **Senior Software Engineer** with **6+ years** architecting, engineering, and scaling mission-critical production systems. Proven track record delivering enterprise-grade platforms at **Centre for Development of Advanced Computing (C-DAC)**, specializing in robust backend architecture, microservices, high-concurrency database design, and intuitive frontend experiences.

- 🔭 Currently architecting enterprise platforms at **C-DAC** (AETP & GLAMS) serving massive multi-tenant user bases.
- 🧠 Actively engineering solutions in **Agentic AI, RAG (Retrieval-Augmented Generation)**, and LLM orchestration with LangChain & LangGraph.
- ⚡ Deep expertise in **Java (Spring Boot / Security / JPA), Microservices, React.js, Python, and SQL/NoSQL databases**.
- 🏆 Recognized with **Best Project Innovation Award** and **Indian Education Awards 2024 (Emerging Technology of the Year)**.
- 🤝 Mentored **100+ engineers and students** in modern full-stack development, software craftmanship, and system design.
